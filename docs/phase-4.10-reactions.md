# Phase 4.10 — реакции вместо анонса, анти-зацикливание, RU-сленг на выходе

> Статус: код в main, на проде — после деплоя. Драйвер — живой тест 2026-07-30.

## Что сказал живой тест

Мост 0.8.1 на macOS, реальный бой. Скорость и реакция — хорошо (Phase 4.7 отработал),
но качество подсказок:

> «как будто анонсера зациклило и ничего полезного, да ещё перевод кривоватый и сам
> голос как у робота» — и в голосе, и в Discord DM одновременно.

Три независимые причины, каждая со своим корнем в коде.

## 1. Анонсер → тренер

**Было.** `voice_phrases.py` умел три шаблона: «Арена. Против X. Килл таргет — Y»,
«Тринкет у X!», «<Абилка> у X!». Всё это — констатация факта, который игрок и так
видит на экране. В DM к нему подклеивалась секция KB «Key cooldowns to track» —
перечень всех КД обеих команд, то есть шум в момент боя.

**Стало.** `orchestrator/reactions.py` — таблица «спелл → что делать» в двух формах:
`voice` (≤9 слов, императив, без ников — TTS их всё равно ломает) и `dm` (одна
строка перед матчап-планом).

| Событие | Было | Стало (голос) |
|---|---|---|
| Ice Block | «Айсблок у Фрости!» | «Блок — стоп бурст, десять секунд по второму.» |
| Vanish | «Ваниш у Секрадж!» | «Ваниш — жди реопен, встаньте вместе.» |
| Тринкет | «Тринкет у Секрадж!» | «Тринкет ушёл — теперь контроль держит, вешай и дожимай.» |

Цифры в репликах взяты из `kb/glossary/abilities.json` (sourced-слой) и продублированы
комментарием у каждой записи. Для пяти способностей записи в глоссарии нет
(`GLOSSARY_GAPS`: divine_shield, shield_wall, retaliation, power_infusion,
elemental_mastery) — там реплики сознательно без секунд, чтобы не экстраполировать
механику 2.4.3. Тир — advice (как `tools/advice_seed.json`), не KB.

`_ABILITY_HINT_KEYS` теперь выводится из таблицы: спелл, на который нечего ответить,
хинтить нечем. Секция «Key cooldowns to track» из боевого DM убрана — полный список
даёт `/matchup`.

## 2. Анти-зацикливание

**Было.** Троттлился только ABILITY (1 в 20с, тот же ключ раз в 60с). TRINKET не
троттлился вообще — а мост поднимает **два** события на один спелл
(`SPELL_CAST_SUCCESS` + `SPELL_AURA_APPLIED`, см. `bridge/combat_tail.py`), так что
дубль тринкета проходил насквозь. ARENA_START переотправляется аддоном при
доуточнении состава (выход из стелса, поздний зум, `addon/Tracker.lua:380`) — игрок
слышал всю стартовую фразу заново, включая предупреждение по угрозам.

**Стало.**

- `HintThrottle.allow(discord_id, event_type, key)` — общий вход для всех типов:
  TRINKET дедуплицируется по источнику (окно 45с, при КД тринкета 2 мин это режет
  только дубли), ABILITY получил ещё и окно тишины 5с после ЛЮБОЙ подсказки
  (стартовый разбор важнее мелкого КД). `allow_ability` оставлен как обёртка.
- Повторный ARENA_START в рамках сессии звучит дельтой: `arena_delta_phrase` →
  «Плюс рога. Килл таргет — маг.» вместо полной фразы. Состав хранится
  мультимножеством (дабл-рога остаётся дабл-рогой). DM остаётся полным — там
  доуточнение приносит реальный матчап-план.

Локальный анти-дубль в мосту (`LocalHintDedup`, окно 6с, сравнение по тексту)
не трогали: он страховка, а не решение — новый бинарь тестеру не нужен.

## 3. RU-сленг на выходе

**Было.** `_clean` разворачивал `[[ability:shadowstep]]` в `shadowstep` — английское
слово внутри русской фразы. Отсюда «кривоватый перевод»: «Рог shadowstep → cheap shot
на ханта». Лексикон `kb/glossary/slang.json` (59 терминов, ревью владельца 2026-06-05)
в коде не использовался вовсе.

**Стало.** `kb/slang.py` → `SlangRenderer`:

- `register: standard` → форма команды («кидни», «блайнд», «преп», «сап», «циклон»);
- `register: colloquial` → по схеме slang.json такие формы мы только ПОНИМАЕМ на входе,
  сами не произносим → корректное `en_name` («Cloak of Shadows»), а не lowercase-слаг;
- нет записи → тоже `en_name` из `abilities.json`.

Резолв слага в запись — по данным (`aliases` из abilities.json, сверка `en_name` ↔
`slang.en`), без хардкод-таблицы: KB пишет `kidney-shot`, лексикон знает `kidney`.

Покрытие сейчас — `python tools/slang_coverage.py`:

```
Ссылок на способности в KB: 3481 (63 уникальных слага)
  русская форма команды : 2274 (65%), слагов 17
  английское имя        : 1207, слагов 46
```

Топ кандидатов в лексикон: `cloak-of-shadows` (112), `pain-suppression` (89),
`barkskin` (61), `entangling-roots` (48), `natures-swiftness` (41). Отдельно:
`gouge` (89), `mana-burn` (74), `evasion` (42), `death-coil` (50), `garrote` (37)
уже В slang.json, но помечены `colloquial` — если владелец переведёт их в `standard`,
покрытие вырастет примерно на 300 вхождений без новой лексики.

## Чего Phase 4.10 НЕ делает

- Голос («робот») — это сторона моста: `local_tts.py` просит `say -v Milena`, и если
  RU-голос не установлен, фоллбэк уходит на дефолтный английский, читающий кириллицу.
  В логе не видно, какой голос выбран. Фикс на стороне моста (лог + `--version` +
  тишина httpx) — отдельным заходом, требует нового бинаря.
- Реакции пока зависят только от способности. Следующий шаг — сузить по нашему
  составу/роли (рог и хилер реагируют на Bloodlust по-разному) через advice-сиды;
  таблица останется фоллбэком.
