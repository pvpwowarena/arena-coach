# Phase 4.22 — KB → аддон, вторая волна: пост-тринкет планы, расы, событийные окна

Дата: 2026-08-01/02. Аддон **0.6.0**. Драйвер: «подготовить аддон получше, компиляция
всей базы для наилучшего коучинга» (Влад, после v0.9.9). Реализует блоки 1-4 из
`docs/proposals/addon-recommendation-triggers.md` (#3, #4, #5, #7, #8, #13 + усечённый #6).
Всё realtime и без сети — канон log-buffer-48kb.

## Что добавлено

### 1. Пост-тринкет планы из KB (`PostTrinket.lua` + `tools/gen_addon_posttrinket.py`)
Тринкет врага — главная развилка боя; секции «If enemy trinkets» теперь скомпилированы
в аддон: `Overlay:NoteTrinket` → `Voice:AnnouncePostTrinket(ключ, класс)` → клип + текст в чат.
- Факты — явная таблица `FACTS` со slug'ом дока-источника; генератор валидирует каждую
  строку против KB (ключ существует, класс у врага, slug среди документов ключа).
  Прозу секций не парсим: варианты/условия в ней надёжно не извлекаются (канон `_OVERRIDES` 4.20).
- 13 правил (все rm-* с чётким пост-тринкет действием), 11 фраз-клипов `pt_*` (фраза
  переиспользуется между матчапами — вычитка не размножается).
- Конфликтные слоты (priest в ключе priest+rogue: disc↔spriest расходятся) НЕ внесены:
  «Нет в KB → нет совета». Раз за матч на класс; общий анти-спам `pt` 15с.
- TODO: rr-* / rp-* / rl-* / rd-* — расширять таблицу после вычитки подхода владельцем.

### 2. «Тринкетов нет — дожимай!» (edge в `NoteTrinket`)
Все живые враги без тринкета → один сигнал за матч. Дальше игрок видит «БЕЗ ТРИНКЕТА» на панели.

### 3. Расовый слой (`UnitRace` на воротах)
- Дворф-прист как килл-таргет → клип «Прист — дворф!» (факт, решение за игроком; KB-цель
  не подменяется) + бейдж «ДВОРФ» на панели. Источник: rm-vs-rogue-priest (stoneform).
- Бейджи «ГНОМ» (вар: escape artist снимает нову) и «АНДЕД» (WotF: фир/гарота) — только панель, без голоса.

### 4. Событийные окна (`Voice:OnCombatLog`)
- `SPELL_CAST_SUCCESS` Intervene → «Интервин — не сапь!» (следующая абилка по хилу уйдёт в вара).
- `SPELL_CAST_SUCCESS` Summon Felhunter → «Сними бафы!» (Devour Magic выбьет из стелса).
- `SPELL_AURA_REMOVED` форм (мишка/кот/дерево/тревел → druid_out, ghost wolf → sham_out) →
  «Друид вышел!» / «Шам вышел!» — окно на сап/блайнд. Реестр форм НЕ заведён осознанно:
  ценен именно момент выхода, edge даёт его без нового состояния (усечение #6 из proposal).
