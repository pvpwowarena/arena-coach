# kb/hypotheses/ — AI-синтез, НЕ проверено, НЕ источник правды

Матчапы, написанные ИИ (Claude) из общих знаний по TBC 2.4.3 **без внешнего источника** (по запросу пользователя на широкий охват).

- **НЕ индексируются ботом** — `KBIndex` сканит только `kb/matchups/` и `kb/drafts/`, так что игрокам как KB-совет это не уходит.
- **НЕ canonical**: намеренно без поля `sources`, поэтому `validate-kb` их не пропустит (схема требует ≥1 источник — это правильно, это и держит «совет = ссылка»).
- Каждый файл помечен `provenance: AI-synthesized, UNVERIFIED` + баннер в теле + теги `ai-synthesized`/`unverified`.

**Чтобы пустить в дело:** найти реальный источник ИЛИ получить ревью топ-игрока → переписать в `kb/drafts/` уже с источником и через обычный `arena_ingest review approve`. До этого — это гипотезы, не база.
