## опенер

_Провенанс: comp-level якоря — Skill Capped (Season 2, Patch 2.5.5): маг+holy-пал **назван C Tier** на обеих страницах (hpala-comps и fmage-comps); наш RM на той же странице — S Tier. Difficulty выведена из тир-разрыва S vs C (по аналогии с rm-vs-вар-маг: D-tier → moderate). Пер-матчап RM-POV источника нет (проверено: AJ-архив 2008 — пары нет в 14 подстраницах Icycake; WT RM-обзор — только counter-list). Пошаговое исполнение синтезировано из механик TBC 2.4.3 — теги `community-sourced`/`needs-top-source`/`synthesized-execution`, нужна верификация топ-RM перед approve._

Ключ матчапа: маг+hpala — **C-tier** пара (Skill Capped): дамаг один (их маг), пала — кастовый хилер без HoT'ов. Слабость против нас: cleanse палы снимает шип/нова-root **с их мага**, поэтому магический контроль вешаем на самого **паладина** — снять поли с палы у них некому (маг не диспеллер). фокус — вражеский **маг**: сквишовее, и без его дамага пала не убьёт нас никогда.

Опенер: рог сап паладина (маг в stealth-опенер не ловится — блинк/новы), открывается на их маге: премед → чип → Hemorrhage → кидни. Наш маг шатерит в окно kidney (нова → ice lance/frostbolt) и держит кс **на хил палы** после выхода из сапа — все хилы палы кастовые, CS в Holy Light = мёртвое окно. Физический контроль рога на их маге cleanse'ом не снимается — стан-чейн важнее поли.

## Alternative опенер

Если их маг открылся по нашему магу (nova + burst): наш маг блок/блинк, рог переключает чип → кидни на их мага и рвёт сетап. шип на паладина в это окно (никто не снимет) — их маг остаётся 1v2.

## If enemy trinkets

Их маг трикетит kidney/сетап → у него остаётся блок: пережидаем (Evasion/отскок), после IB он голый — добив под кс. Пала трикетит шип → re-sheep/блайнд; пала bubble → killwindow закрыт на 12с: маг кайтит, рог ваниш-ресет или доводит их мага; после бабла у палы нет второй кнопки — снова CS на хил и добив мага. Берегись подж по нашему магу в бурст-окно — пала держит его для пила.

## Common mistakes

- Вешать шип/нова на их мага при свободном пале — cleanse снимает мгновенно; магический CC — на палу, физический — на мага.
- Не держать кс под кастовые хилы палы — без CS у C-tier пары нет таймера смерти.
- Разменивать бурст в поднятый bubble/блок вместо ресета.
- Стоять кучно под подж + nova их мага.

## Key cooldowns to track

- enemy: пал — bubble (Divine Shield), подж, Blessing of Freedom, cleanse-спам, тринка; маг — блок, блинк, кс, шип, нова, Icy Veins, тринка.
- ours: кс, шип, нова, кидни, блайнд, ваниш, Evasion, блок, тринка.
