## Opener

_«Самый частый комп, с которым RM встретится в TBC. Оба таргета убиваемы — зависит от того, кого нашли первым» (DLEZ7Yi4-jU 22:21). Сложность в источнике не названа — `moderate` до ревью. NB: для resto-варианта друида есть отдельный документ rm-vs-rogue-rdruid._

Нашёл рога — не открывайся мгновенно, сначала поищи друида. Не нашёл — ре-[[ability:sap]] рога → [[ability:premed]] → [[ability:cheap-shot]] → [[ability:rupture]] полным комбо, БЕЗ раннего kidney: спамишь урон, bleed запрещает ему сбежать (DLEZ7Yi4-jU 22:31–22:48).

Faerie fire по тебе — [[ability:cloak-of-shadows]] → мгновенный [[ability:vanish]] (DLEZ7Yi4-jU 22:48). Рог тринкетит первый чип — «правило на входе: тринкет — смерть»; тринкетит и второй [[ability:cheap-shot]] — значит третий чип его добивает (DLEZ7Yi4-jU 22:55).

Нашёл друида первым (DLEZ7Yi4-jU 23:08): [[ability:premed]] → [[ability:cheap-shot]] → мгновенный [[ability:vanish]] — сдерживаем друида и выигрываем время магу, их рог почти наверняка рядом и ловит тебя на чип. Затем повторный [[ability:cheap-shot]] → [[ability:kidney]]; друид тринкетит → тринкетишь ответный стан их рога → [[ability:blind]] рога → добиваешь друида (DLEZ7Yi4-jU 23:21–23:37).

## If enemy trinkets

Их рог в этом матчапе склонен тринкетить чип-шоты подряд — каждый следующий чип без его тринкета приближает добив (DLEZ7Yi4-jU 22:55). Друид тринкетит [[ability:kidney]] → размен: свой тринкет на стан рога, [[ability:blind]] на рога, друид остаётся без прикрытия (DLEZ7Yi4-jU 23:29).

## Common mistakes

- Ранний [[ability:kidney]] вместо полного [[ability:rupture]] по рогу: без bleed он уходит в vanish (DLEZ7Yi4-jU 22:31, тот же принцип — 4:38 в главе mirror).
- Мгновенное открытие на первого увиденного без поиска второго стелсера (DLEZ7Yi4-jU 22:31).
- Сжигать тринкет на первый полный стан, когда давление ещё не смертельно (DLEZ7Yi4-jU 23:52 — соседняя глава, общий принцип пары rogue+druid).
