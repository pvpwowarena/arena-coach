## Opener

_Провенанс: comp-level якоря — Skill Capped (Season 2, Patch 2.5.5): mage+holy-paladin **назван C Tier** на обеих страницах (hpala-comps и fmage-comps); наш RM на той же странице — S Tier. Difficulty выведена из тир-разрыва S vs C (по аналогии с rm-vs-warrior-mage: D-tier → moderate). Пер-матчап RM-POV источника нет (проверено: AJ-архив 2008 — пары нет в 14 подстраницах Icycake; WT RM-обзор — только counter-list). Пошаговое исполнение синтезировано из механик TBC 2.4.3 — теги `community-sourced`/`needs-top-source`/`synthesized-execution`, нужна верификация топ-RM перед approve._

Ключ матчапа: mage+hpala — **C-tier** пара (Skill Capped): дамаг один (их маг), пала — кастовый хилер без HoT'ов. Слабость против нас: cleanse палы снимает [[ability:sheep]]/[[ability:nova]]-root **с их мага**, поэтому магический контроль вешаем на самого **паладина** — снять поли с палы у них некому (маг не диспеллер). Kill target — вражеский **mage**: сквишовее, и без его дамага пала не убьёт нас никогда.

Опенер: рог [[ability:sap]] паладина (маг в stealth-опенер не ловится — блинк/новы), открывается на их маге: [[ability:premed]] → [[ability:cheap-shot]] → [[ability:hemo]] → [[ability:kidney-shot]]. Наш маг шатерит в окно kidney ([[ability:nova]] → ice lance/frostbolt) и держит [[ability:counterspell]] **на хил палы** после выхода из сапа — все хилы палы кастовые, CS в Holy Light = мёртвое окно. Физический контроль рога на их маге cleanse'ом не снимается — стан-чейн важнее поли.

## Alternative opener

Если их маг открылся по нашему магу (nova + burst): наш маг [[ability:ice-block]]/blink, рог переключает [[ability:cheap-shot]] → [[ability:kidney-shot]] на их мага и рвёт сетап. [[ability:sheep]] на паладина в это окно (никто не снимет) — их маг остаётся 1v2.

## If enemy trinkets

Их маг тринкетит kidney/сетап → у него остаётся [[ability:ice-block]]: пережидаем ([[ability:evasion]]/отскок), после IB он голый — добив под [[ability:counterspell]]. Пала тринкетит [[ability:sheep]] → re-sheep/[[ability:blind]]; пала bubble → killwindow закрыт на 12с: маг кайтит, рог [[ability:vanish]]-ресет или доводит их мага; после бабла у палы нет второй кнопки — снова CS на хил и добив мага. Берегись [[ability:hammer-of-justice]] по нашему магу в бурст-окно — пала держит его для пила.

## Common mistakes

- Вешать [[ability:sheep]]/[[ability:nova]] на их мага при свободном пале — cleanse снимает мгновенно; магический CC — на палу, физический — на мага.
- Не держать [[ability:counterspell]] под кастовые хилы палы — без CS у C-tier пары нет таймера смерти.
- Разменивать бурст в поднятый bubble/[[ability:ice-block]] вместо ресета.
- Стоять кучно под [[ability:hammer-of-justice]] + nova их мага.
