## Opener

_Провенанс: новый состав **RL (Rogue / Warlock 2v2, SL/SL)**. Источники — Icy Veins (Rogue/Resto Druid — «double stealth with powerful CC chains»; наш SL/SL Warlock/Rogue best-tier) и Wowhead (Rogue/Warlock план). Per-matchup исполнение синтезировано из механик TBC 2.4.3; теги `community-sourced`/`needs-top-source`/`synthesized-execution`/`new-comp-rl`. Нужна верификация топ-RL._

Тяжёлый матчап: у них хилер + вражеский рог с мощными CC-цепями и restealth. Наша задача — **не дать их рогу свободно сетапить** и продавить друида.

Килл-таргет — **друид** (снять хил). Их рог без хилера — просто DPS, которого мы переживём через [[ability:soul-link]]/[[ability:siphon-life]].

- Стартовый размен стелсов: [[ability:sap]] на их рога (не на друида — иначе их рог свободно опенит). Открываемся на друида: рог [[ability:cheap-shot]] → [[ability:kidney-shot]], варлок [[ability:fear]] на их рога + [[ability:curse-of-tongues]] на друида.
- Их рог будет [[ability:cheap-shot]]/[[ability:kidney-shot]] по нашему варлоку (sustain-мотор) — наш рог peel'ит его [[ability:blind]], варлок мгновенным [[ability:howl-of-terror]] сбрасывает давление.
- Против друид-escape держи [[ability:shadowstep]] (гэп) + [[ability:seduction]] пета как второй слой контроля.

## Alternative opener

Если их рог заопенил первым (по нашему варлоку): [[ability:soul-link]]/healthstone держат, варлок [[ability:howl-of-terror]] instant + [[ability:drain-life]] за LoS, наш рог [[ability:blind]] их рога и [[ability:vanish]] → [[ability:sap]] для перезахода. Не паникуй свапами — верни контроль, затем всей цепью на друида.

## If enemy trinkets

Друид тринкетит рог-стан/[[ability:fear]] → NS-хил/travel — не добивай в открытый NS; свяжи вторым CC ([[ability:blind]]/[[ability:gouge]]). Их рог тринкетит [[ability:kidney-shot]] → [[ability:vanish]]-restealth: жди re-opener, держи [[ability:evasion]] превентивно и [[ability:fear]] наготове, чтобы поймать его из стелса.

## Common mistakes

- Sap'нуть друида вместо их рога на старте — освобождаешь их опенер; sap всегда на их рога.
- Тунеллить их рога — он без хилера умрёт сам под нашим давлением, но это не kill-цель; дави друида.
- Слить фир-цепь в одной [[ability:dr]] — чередуй фир варлока / рог-стан / [[ability:seduction]].
- Бросить варлока под рог-стан-лок — [[ability:blind]]/[[ability:howl-of-terror]] обязаны снимать давление с sustain-мотора.
