## Opener

_Провенанс: новый состав **RL (Rogue / Warlock 2v2, SL/SL)**. Источники — Icy Veins (Rogue/Disc — топ-comp: «priests enable Rogue restealths through dispels and crowd control removal»; наш SL/SL Warlock/Rogue best-tier) и Wowhead (Rogue/Warlock план). Per-matchup исполнение синтезировано из механик TBC 2.4.3; теги `community-sourced`/`needs-top-source`/`synthesized-execution`/`new-comp-rl`. Нужна верификация топ-RL._

Сильный вражеский состав: прист дизпелит (открывает restealth рогу) + щитит + Psychic Scream. Килл-таргет — **прист**: без него их рог в 1v2 не вытянет; но прист скользкий (Fade/LoS/дизпел).

- [[ability:sap]] их рога на старте (не приста — иначе их рог свободно опенит). Открытие на приста: рог [[ability:cheap-shot]] → [[ability:kidney-shot]], варлок [[ability:spell-lock]] на хил + [[ability:curse-of-tongues]].
- Их рог будет тренить нашего варлока (sustain-мотор) — наш рог peel'ит [[ability:blind]], варлок [[ability:howl-of-terror]] instant + [[ability:drain-life]] за LoS.
- **Фир-война:** их прист Psychic Scream'ит, наш варлок фирит — следи за [[ability:dr]] fear; заткни приста фиром/[[ability:seduction]] в burst-окно.

## Alternative opener

Если их рог заопенил по варлоку: [[ability:soul-link]]/healthstone держат, варлок [[ability:howl-of-terror]] + уход за LoS; наш рог [[ability:blind]] их рога, [[ability:vanish]] → [[ability:sap]] для перезахода. Верни контроль, затем всей CC-цепью на приста. Прист дизпелит наши DoT'ы — обновляй давление и держи [[ability:curse-of-tongues]].

## If enemy trinkets

Прист тринкетит рог-стан → [[ability:pain-suppression]]/щит/Fade: не жги burst под pain-suppression, вынуди дефы. Их рог тринкетит [[ability:kidney-shot]] → [[ability:vanish]]-restealth (прист сдизпелит наш slow/root): держи [[ability:evasion]] превентивно и [[ability:fear]] чтобы поймать его из стелса.

## Common mistakes

- Sap на приста вместо их рога — освобождаешь их опенер по варлоку.
- Тунеллить их рога — не kill-цель; дави приста и затыкай хил.
- Слить фир-цепь в одной [[ability:dr]] fear в тройной фир-войне (их прист + наш варлок).
- Бросить варлока под рог-стан-лок без [[ability:blind]]/[[ability:howl-of-terror]] — теряем sustain.
