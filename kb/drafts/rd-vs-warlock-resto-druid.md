## Opener

_Провенанс: новый состав **RD (Rogue / Resto Druid 2v2)**. Источники — Icy Veins Resto Druid guide (наш [[ability:cyclone]]-лок, [[ability:barkskin]] в стане, NS-инстант) и Icy Veins 2v2 rankings (SL/RDruid — «strong spread damage; strong crowd control»). Исполнение синтезировано из механик TBC 2.4.3; теги `community-sourced`/`needs-top-source`/`synthesized-execution`/`new-comp-rd`. Нужна верификация топ-RD._

SL/RDruid — spread-DoT + [[ability:fear]] + двойной sustain (Soul Link варлок + друид-хил). Угрозы нашему **друиду**: фир-чейн (у нас нет тремора), [[ability:seduction]] сакубы, [[ability:spell-lock]] фелхантера по касту хила, [[ability:devour-magic]] сдирает наш [[ability:cyclone]]/HoT. Это длинный размен — режем один sustain-мотор.

Килл-таргет — **их друид** (варлок под Soul Link слишком жирный). Fallback — варлок, если друид зашёл в NS/travel.

- Рог [[ability:sap]] варлока (лишаем фир/[[ability:seduction]]-сетапа на старте), открываемся на их друида: [[ability:cheap-shot]] → [[ability:kidney-shot]], wound-poison, кикаешь хил-касты.
- В окно стана наш друид [[ability:cyclone]] варлока (стоп фир/DoT) — но помни: варлок может [[ability:devour-magic]] снять cyclone/HoT, так что чередуй с рог-контролем.
- Наш рог [[ability:cloak-of-shadows]] сбрасывает [[ability:fear]]+DoT с себя; друида от фира спасаем спредом и LoS. Пил пета/варлока — [[ability:entangling-roots]].

## Alternative opener

Открылись фиром по нашему друиду: [[ability:barkskin]] + NS-инстант-хил, тринкет под [[ability:fear]] если чейнят; рог [[ability:blind]] варлока / [[ability:kidney-shot]] на его каст. Верни друида в игру, затем снова весь контроль-чейн на их друида.

## If enemy trinkets

Их друид тринкетит рог-стан → NS/[[ability:travel-form]]/[[ability:barkskin]] — не добивай в открытый NS, свяжи [[ability:blind]]/[[ability:cyclone]]. Варлок тринкетит [[ability:kidney-shot]] → [[ability:fear]]/[[ability:death-coil]], сидит на Soul Link + healthstone — держи [[ability:cloak-of-shadows]] и [[ability:blind]] на его фир-окно.

## Common mistakes

- Тунеллить варлока — Soul Link + друид-хил тащат; дави их друида.
- Полагаться на один [[ability:cyclone]] по друиду — варлок [[ability:devour-magic]] его снимет; держи рог-стан как основной лок.
- Ловить [[ability:fear]]-чейн группой — спред + [[ability:cloak-of-shadows]] рогой + LoS сакубы.
- Забыть wound-poison на их друиде — его хил не проседает, размен затягивается им в плюс.
